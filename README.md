# Portfólio — Júlia Marques Fialho

Site estático (HTML + CSS) voltado para recrutadores.

## Publicar na Vercel
1. Crie um repositório novo no GitHub (ex.: `portfolio`) e envie `index.html` e `curriculo-julia-marques-fialho.pdf`.
   Envie também as pastas `img/` e `demo/` (a demo do VisionFinance roda dentro do portfólio).
2. Na Vercel: **Add New → Project**, importe o repositório e clique em **Deploy** (não precisa configurar build).
3. Em **Settings → Domains**, troque o nome para algo como `juliamarques-dev.vercel.app`.

Para atualizar o currículo, substitua o PDF mantendo o mesmo nome do arquivo.
